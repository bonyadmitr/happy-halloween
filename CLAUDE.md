# CLAUDE.md — память проекта

Контекст для ИИ-ассистента и разработчика. Держи актуальным.

## Что это

Сайт-поздравление с Хэллоуином. Сделан по образцу `../happy_birthday` (тот же стек,
движок ритм-игры, PWA и тесты), но со своей сценой и темой.

## Сцена (одна страница)

1. **Интро** — злая тыква-фонарь (прищур, клыкастая ухмылка, корявый сухой черенок) со свечой, которая едва тлеет; тап (или тряска телефона) →
   свеча вспыхивает, из тыквы вылетают призраки/мыши/конфеты → сайт. Тап стартует музыку.
2. **Hero** — «Счастливого / Halloween» (капающий Creepster) + подзаголовок, staggered-вход.
3. **Финал** — большая горящая тыква; тап → салют эмодзи 👻🦇🕷️🍬🍭🎃💀 из её лица.
   Кнопка внизу «Happy Halloween» (Creepster) — обычный залп конфетти.
4. **Ритм-игра** над тыквой — «Играть в такт»: ноты-призраки едут к кольцу, жмёшь на тыкву
   (или полосу) в такт уже играющей песне. Проиграть нельзя; конец — на границе лупа.

Атмосфера (фон, всё декоративное): ночное небо со звёздами, луна, паутина в верхних углах,
летучие мыши через небо, силуэт кладбища с деревом, ползущий туман, всплывающие призраки/конфеты,
**паучки на нитках** (маятник; тап — убегает под потолок и через 2–4 с спускается).

## Стек и принципы

- Чистые **HTML + CSS + JS, без сборки и без фреймворка**.
- `canvas-confetti` вшит локально (`js/confetti.js`). Внешне — только Google Fonts
  (Creepster + Underdog).
- **iPhone-first (Safari)**. **PWA** (манифест + SW, офлайн).
- Песня: **This Is Halloween** (The Nightmare Before Christmas), луп 74.46 с,
  вырезан по долям (104 доли = 13 тактов по 8) — шов лупа попадает в ритм.

## Гочи (не наступить повторно)

- **Creepster — только латиница.** Заголовок `hero.title` держать латиницей; кириллицу
  рисует Underdog. Капли Creepster свисают ниже базовой линии → `padding` на `.hero-title`
  обязателен (иначе `background-clip:text` срежет).
- **Фикс-слои с движущимися детьми → `overflow: clip` + `contain: layout paint size`.**
  Так сделано у `.bg` (мыши летят transform'ом за край), `.floaties`, `.spiders`. Без этого
  iOS даёт горизонтальный скролл (Chromium-превью его не показывает — ловит WebKit-тест).
- **Градиенты тыквы — в `.svg-defs`, а не внутри шаблона.** Клон шаблона дважды дал бы
  дубли id; и `.svg-defs` нельзя `display:none` — браузеры перестают рисовать градиенты.
- **CSS `fill` перебивает SVG-атрибут `fill`.** У кладбища цвет задан на `<svg>` (наследуется),
  а не на `path` — иначе дерево (`fill="none"`, штрихи) зальётся.
- **Холм кладбища шире viewBox** (`overflow: visible`, `meet`) — на широких экранах тянется
  до краёв, на телефоне не обрезает дерево (было с `slice`).
- **Туман — `background-position`, не transform**: бесшовный (сдвиг = ширина тайла) и не
  может дать переполнение.
- **Паучок висит на `transform: translateY(--drop)`**, нитка — `::before` вверх на `--drop`,
  маятник крутится вокруг точки крепления (`transform-origin: 50% calc(-1 * --drop)`).
  Пока паучок спускается (1.6 с), он ещё вне экрана — тесты ждут `toBeInViewport()`.
- **Автоплей на iOS** — только в жесте (тап по тыкве / кнопке).
- **`hidden` + `display`** — для скрываемых элементов держать `.x[hidden]{display:none}`.
- **`dvh`, а не `vh`** для секций. **reduced-motion** уважается (частицы и мыши выключены).
- **Ритм-игра:** часы — только `audio.currentTime`; `targetPct` (12%) в `rhythm.js` синхронен с
  `.rhythm-target{left:12%}`. Полоса — НАД тыквой (рука не закрывает).
- **SW отключён на localhost**, версия кэша `halloween-vN` — поднимать при смене ассетов.
- **Меняешь тыкву/палитру → `npm run icons`** (цвета фона иконки зашиты в `gen-icons.mjs`).
- **Меняешь песню → `tools/beatmap/regen.sh`** (путь к mp3 — в скрипте). Тест «карта битов
  соответствует лупу» падает, если длительность mp3 и карты разошлись.

## Запуск и проверка

```bash
python3 -m http.server 8123   # http://localhost:8123
npm test                      # E2E: WebKit(iPhone) + реальный Chrome, ~25с
npm run icons                 # пере-генерировать PWA-иконки
tools/beatmap/regen.sh [MIN_GAP] [TOP]   # пере-собрать карту битов (дефолт 0.55 0.70 → 80 нот)
```

venv для карты битов (один раз; проверено на Python 3.12, на системном 3.14 не проверялось):
`uv venv --python 3.12 tools/beatmap/.venv && uv pip install --python tools/beatmap/.venv/bin/python librosa`
